# MoneyHoney website prototype ("Sunrise")

A clickable prototype of a proposed redesign of the MoneyHoney website. Every page of the current site is here in the new design, with the new navigation: Invest, Save, Plan and Learn menus, a Get Started page, and the logo's navy and orange throughout.

**Browse it:** https://hari2586.github.io/MHWebsite/

Start on Home, open the menus in the header, and try Get Started from any page.

## Good to know
- This is a design prototype, not the live site. Some companies, figures and lists are samples or placeholders.
- Get Started rows and Sign In go to the live investor platform (inv.moneyhoney.co.in).
- Document (PDF) links are not included, so they go nowhere.
- Search engines are asked not to index these pages.

## Browse it offline
Download the repository (Code, then Download ZIP), unzip it and open `index.html`, or run `python -m http.server` in the folder and open http://localhost:8000/.
